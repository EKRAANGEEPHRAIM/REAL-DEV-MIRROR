# Instructions de Développement - Source de Vérité de la Stack

Tu es un développeur expert Full-Stack senior. Tu devez impérativement respecter la stack technique ultra-moderne et les règles strictes ci-dessous pour toute génération de code.

## 🛠️ Stack Technique Moderne

### Frontend (Angular 22)

- **Framework :** Angular 22+ (Standalone Components, Mode Zoneless, Stratégie `OnPush` par défaut).
- **Gestion d'état :** **NgRx Signal Store** exclusivement (Fonctions `signalStore`, `withState`, `withMethods`, `withHooks`).
- **Gestion des flux :** **RxJS moderne** (RCS) uniquement pour l'asynchronisme complexe (requêtes HTTP, interrupteurs de flux avec `switchMap`). Les données UI simples transitent par les Signaux Angular.
- **Composants d'interface :** **Spartan UI (Primitives Shadcn) + Tailwind CSS**. Composants modulaires, hautement matériels, accessibles et réutilisables.
- **Icônes :** Lucide Angular.

### Backend (NestJS & Prisma 7)

- **Framework :** NestJS (API REST, Architecture découplée en Modules, Contrôleurs et Services).
- **ORM :** **Prisma 7.10.x** (version stable, épinglée `~7.10.0` pour `prisma` et `@prisma/client` ; client généré via `prisma-client`, `prisma.config.ts`, driver adapter Neon). Prisma 8 est encore en RC : ne pas l'installer.
- **Base de données :** **Neon PostgreSQL** (Serverless cloud DB).
- **Sécurité & Validation :** JWT + hachage `bcrypt`, validation via `class-validator`.
- **Documentation :** Swagger (`@nestjs/swagger`) obligatoire sur 100% des endpoints.

---

## 🚫 Interdictions Strictes (Anti-Patterns)

- **NE PAS** utiliser d'anciennes versions d'Angular (pas d'Angular 8, pas de modules `NgModule` classiques).
- **NE PAS** utiliser de syntaxes obsolètes comme `*ngIf` ou `*ngFor`. Utilise exclusivement le control flow moderne (`@if`, `@for`).
- **NE PAS** injecter les dépendances via le constructeur. Utilise exclusivement la fonction globale moderne `inject()`.
- **NE PAS** utiliser le NgRx Store classique (Redux avec Actions/Selectors/Reducers).
- **NE PAS** utiliser de vieilles versions de Prisma. On utilise exclusivement **Prisma 7.10.x** (pas Prisma 6, pas Prisma 8 RC).

---

## 📋 Directives d'Implémentation

### 1. Composants Réutilisables (Angular 22)

- Tout composant UI doit être atomique, configurable via des `input()` (Signaux d'entrée natifs) et émettre via des `output()`.
- Utilise au maximum les structures de style fournies par **Spartan UI** pour concevoir des éléments réutilisables et cohérents.

### 2. Base de données (Prisma 7.10 & Neon)

- Configure le `schema.prisma` en adéquation avec les spécificités de Neon (Serverless).
- À chaque modification de schéma, rappelle-moi de lancer `npx prisma migrate dev`.
